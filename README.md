# Review Classifier

Автоматизированный скрипт для анализа отзывов с использованием LLM. Скрипт читает отзывы из CSV-файла, классифицирует их по тональности (положительная/отрицательная/нейтральная) и определяет тему отзыва, сохраняя результаты в формате JSON.

## Описание работы

Скрипт реализует следующий пайплайн:

1. Чтение входных данных из CSV-файла
2. Отправка каждого отзыва в LLM через API OpenRouter
3. Получение структурированного ответа с классификацией
4. Сохранение результатов в JSON-файл

Используется модель Qwen 3.5 (qwen/qwen3-235b-a22b-2507) для анализа тональности и определения темы каждого отзыва.

## Требования

- Python 3.10 или выше
- API ключ OpenRouter

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd Analytics\ Second\ lab
```

2. Создайте виртуальное окружение:
```bash
python -m venv .venv
```

3. Активируйте виртуальное окружение:

На Windows:
```bash
.venv\Scripts\activate
```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

5. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

6. Отредактируйте файл `.env` и добавьте ваш API ключ OpenRouter:
```
OPENROUTER_API_KEY="ваш_api_ключ_здесь"
OPENROUTER_MODEL="qwen/qwen3.5-35b-a3b"
OPENROUTER_BASE_URL="https://openrouter.ai/api/v1"
```

## Использование

Запустите скрипт, указав CSV-файл с отзывами (разделитель - точка с запятой):
```bash
python main.py test_reviews.csv
```

Результаты будут сохранены в файл `analysis_results.json`.

## Формат входных данных

CSV-файл должен содержать столбцы:
- `review_id` — идентификатор отзыва
- `review_text` — текст отзыва

Пример формата:
```
review_id;review_text
1;Очень ароматный чабрец! В чай совсем маленькую щепотку добавляю и получается насыщенный вкус
2;Таблетками не могла вылечить свой бронхиальный кашель...
```

Разделитель по умолчанию — точка с запятой (`;`).

## Формат выходных данных

Результат сохраняется в JSON-формате:
```json
[
    {
        "review_sentiment": "positive",
        "review_topic": "product_quality",
        "review_text": "Очень ароматный чабрец! В чай совсем маленькую щепотку добавляю..."
    },
    {
        "review_sentiment": "negative",
        "review_topic": "product_quality",
        "review_text": "Ну очень много мусора!!! Я перебрала всю пачку..."
    }
]
```

Каждый объект содержит:
- `review_sentiment` — тональность отзыва (positive, negative, neutral)
- `review_topic` — тема отзыва
- `review_text` — исходный текст отзыва

## Обработка ошибок

Если LLM не удается обработать отзыв, в результате для этого отзыва будет добавлена запись:
```json
{
    "error": "ошибка при обращении к llm",
    "review_text": "исходный текст отзыва"
}
```
